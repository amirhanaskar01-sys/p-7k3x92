ПЛАНИРОВЩИК КАК ПРИЛОЖЕНИЕ (версия 2)

Файлы: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png

ПЕРВАЯ УСТАНОВКА
1. github.com -> New repository (имя латиницей, трудно угадать, тип Public) -> Create repository.
2. Add file -> Upload files -> выберите ВСЕ шесть файлов -> Commit changes.
3. Settings -> Pages -> Source: Deploy from a branch -> main, папка / (root) -> Save.
4. Через 1-2 минуты ссылка: https://ВАШ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/
5. Откройте её в Chrome на телефоне: меню (три точки) -> Установить приложение.

ОБНОВЛЕНИЕ
1. Откройте свой репозиторий на github.com.
2. Add file -> Upload files -> выберите НОВЫЕ index.html и sw.js (имена те же) -> Commit changes.
3. Подождите 2-3 минуты.
4. В приложении: Настройки -> Приложение -> Проверить обновление. Данные не стираются.

Перенос данных: Настройки -> Данные -> Показать данные -> Копировать; на новом месте вставить и нажать Загрузить.
PIN-код: Настройки -> PIN-код.
